# Figure Archetypes

## 1. Atlas page

- cohort or sample schema
- major-compartment UMAP
- batch/condition UMAP
- marker dotplot
- composition panel
- one program-support panel

## 2. Response page

- treatment and response definition
- lineage/subcluster atlas
- patient-level composition comparison
- DEG or program support
- one validation panel

## 3. Spatial page

- spatial workflow
- mapped cell-state view
- neighborhood summary
- interaction or niche panel
- histology validation

## 4. Trajectory page

- subcluster atlas
- trajectory/velocity panel
- dynamic signatures
- lineage/clonal support
