# `single-cell-figure` skill

A figure-focused skill for single-cell papers, with explicit large discrete palettes and single-cell-specific panel rules.

## What it does

- provides fixed hex-coded palettes for `10`, `24`, and `80` category scenarios
- defines stable color systems for major lineages, treatment groups, and spatial overlays
- adapts `nature-figure`-style typography, SVG export, and figure contract to single-cell work
- organizes atlas, response, spatial, and trajectory figures into reusable panel archetypes
