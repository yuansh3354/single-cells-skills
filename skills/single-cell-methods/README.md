# `single-cell-methods` skill

A methods-focused skill for choosing, adapting, and extending single-cell analysis workflows.

## What it does

- organizes method choice by scientific task
- records parameter defaults from the provided pipeline
- highlights when to use `Harmony`, `BBKNN`, `scVI`, `MAST`, `AUCell`, `SCENIC`, `scVelo`, `CellChat`, `inferCNV`, `RCTD`, and related branches
- captures special-case analysis strategies seen in high-quality papers
